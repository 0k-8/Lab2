# TCP-сервер команд

Навчальний TCP-сервер на Go, який приймає текстові команди від клієнтів. Сервер слухає адресу `localhost:9000` і обробляє кожне підключення окремо.

## Вимоги

- Go версії, сумісної з вимогою проєкту `go 1.27.1` у `go.mod`.
- Клієнт TCP, наприклад `nc` (Netcat).

## Запуск

У каталозі проєкту запустіть:

```sh
go run .
```

Після запуску сервер повідомить, що слухає `localhost:9000`. Для зупинки сервера натисніть `Ctrl+C`.

За потреби зберіть виконуваний файл командою:

```sh
go build
```

## Підключення та команди

В іншому терміналі відкрийте TCP-з’єднання:

```sh
nc localhost 9000
```

Після привітання введіть одну з команд. Команди не залежать від регістру; кожну потрібно завершувати клавішею Enter.

| Команда | Дія |
| --- | --- |
| `ECHO <текст>` | Повертає переданий текст із префіксом `[ECHO]:`. Якщо текст не вказано, сервер повертає вбудований текст за замовчуванням. |
| `TIME` | Повертає поточний час у форматі RFC3339. |
| `CLOSE` або `QUIT` | Завершує поточне клієнтське з’єднання. Сервер продовжує працювати. |

Приклад сеансу:

```text
Ласкаво просимо до TCP-сервера команд!
Введіть команду (ECHO, TIME, QUIT/CLOSE):
ECHO Привіт, сервере!
[ECHO]: Привіт, сервере!
TIME
[TIME]: 2026-10-25T12:00:00Z
QUIT
До побачення!
```

Значення часу в прикладі умовне: сервер формує його під час виконання.

Невідома команда повертає повідомлення про помилку зі списком доступних команд. Порожні рядки ігноруються.

## Адреса сервера

Адреса й порт задані в `main.go` як `localhost` і `9000`. Сервер приймає локальні підключення; змінити адресу або порт можна у вихідному коді.
